# Privacy

- **No telemetry.** wwt-lite does not collect usage data, analytics or crash reports.
- **Local only.** Pages, screenshots, page snapshots and logs stay on your computer, in the wwt-lite data folder. They are sent only to the AI agent you run yourself, as part of the task you give it.
- **Network.** wwt-lite contacts the internet only for (1) the websites you or your agent open, and (2) GitHub, when you install or run `wwt-browser upgrade`, to download releases.
- **Your browser data.** wwt-lite never reads your normal Chrome profile. Its own profile can be deleted with `wwt-browser profile delete <id>` or by uninstalling.
